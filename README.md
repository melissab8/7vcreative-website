# 7vcreative.co.uk

Static one-page site for 7V Creative, hosted on Cloudflare Pages.

- `index.html` – home page
- `privacy.html` – privacy notice (served at /privacy)
- `assets/` – images, compressed videos, styles

Cloudflare Pages settings: no framework, no build command, output directory `/`.
